# 크롬 MCP 설치 가이드

클로드(Claude Code)가 크롬 브라우저를 직접 움직이게 만드는 프로그램입니다.
"네이버 들어가서 오늘 날씨 알려줘" 같은 부탁을 대신 해줍니다.

**컴퓨터를 잘 몰라도 괜찮습니다.** 순서대로 따라 하면 10분 안에 끝납니다.

## 어디부터 보면 되나요

이 문서는 두 부분으로 나뉩니다. **본인 컴퓨터에 해당하는 쪽만 보세요.**

- **윈도우를 쓰신다면 → 1부 (윈도우)** 만 보시면 됩니다.
- **맥을 쓰신다면 → 2부 (맥)** 로 바로 넘어가세요. 1부는 안 읽으셔도 됩니다.

마지막의 "이걸 설치하면 뭐가 좋은가요"와 "알아두면 좋은 것"은 양쪽 공통입니다.

## 시작 전에 준비할 것 3가지 (공통)

**1. 크롬 브라우저**

없으면 google.com/chrome 에서 받으세요.

**2. 클로드 코드 (Claude Code)**

없어도 됩니다. 아래에서 같이 설치합니다.

**3. 클로드 유료 플랜**

Pro, Max, Team 중 하나가 필요합니다.
**무료 계정으로는 클로드 코드를 쓸 수 없습니다.** 이건 앤트로픽 정책이라 우회할 방법이 없습니다.

# 1부. 윈도우

윈도우 사용자는 여기만 따라 하시면 됩니다.

## 윈도우 0단계. 클로드 코드 설치하기

이미 클로드 코드를 쓰고 계시면 **1단계로 건너뛰세요.**

### 파워셸(PowerShell) 여는 법

컴퓨터에 글자로 명령을 내리는 창입니다. 검은 화면이 낯설겠지만 몇 줄만 붙여넣습니다.

1. 키보드에서 **윈도우 키**를 누릅니다.
2. **powershell** 이라고 칩니다.
3. "Windows PowerShell" 이 나오면 **Enter**를 누릅니다.

### 설치 명령 붙여넣기

아래 줄을 복사해서 창에 **마우스 오른쪽 클릭**으로 붙여넣고 Enter를 누릅니다.

```
irm https://claude.ai/install.ps1 | iex
```

설치가 끝나면 창을 닫고 **새로 엽니다.** 방금 설치한 프로그램을 컴퓨터가 인식하게 하려는 것입니다.

### 로그인

새 창에 이렇게 치고 Enter:

```
claude
```

브라우저가 열리면서 로그인하라고 나옵니다. 클로드 계정으로 로그인하면 됩니다.
로그인이 끝나면 클로드 코드가 실행됩니다.

## 윈도우 1단계. 명령 한 줄 붙여넣기

이제 크롬 MCP를 설치합니다.

> 클로드 코드가 실행 중이라면 먼저 빠져나와야 합니다. **Ctrl + C를 두 번** 누르면 됩니다.

파워셸에 아래 한 줄을 붙여넣고 Enter를 누르세요.

```
irm https://raw.githubusercontent.com/cw02326/auto-chrome-mcp/main/install.ps1 | iex
```

이제 기다리면 됩니다. 2분에서 5분쯤 걸립니다. 이 한 줄이 이런 일을 알아서 합니다.

- 필요한 프로그램 설치
- 크롬과 클로드를 연결하는 통로 만들기
- 클로드 코드에 등록
- 크롬 확장 프로그램 내려받기

> **"다시 실행해 주세요" 라는 노란 글씨가 나왔다면?**
> 당황하지 마세요. 필요한 프로그램(Node.js)을 방금 새로 깔았다는 뜻입니다.
> 창을 닫고 새로 연 다음, 위 명령을 **한 번만 더** 붙여넣으면 됩니다.

## 윈도우 2단계. 크롬에 확장 프로그램 등록하기

**여기가 유일하게 사람이 직접 해야 하는 단계입니다.**
크롬 정책상 이 화면은 프로그램이 대신 클릭할 수 없습니다. 클로드도 못 합니다.

1단계가 끝나면 **크롬의 확장 프로그램 화면**과 **폴더 창**이 자동으로 열립니다.
클릭 3번이면 끝납니다.

1. 크롬 화면 **오른쪽 위**의 **개발자 모드** 스위치를 켭니다. 파란색이 되면 켜진 것입니다.
2. **왼쪽 위**에 새로 나타난 **압축해제된 확장 프로그램을 로드합니다** 버튼을 누릅니다.
3. 폴더 선택 창이 뜨면 **문서 > AutoChromeMCP-확장프로그램** 폴더를 고르고 **폴더 선택**을 누릅니다.

목록에 **Auto Chrome MCP** 가 나타나면 성공입니다.

> 창이 자동으로 안 열렸다면, 크롬 주소창에 **chrome://extensions** 를 직접 입력하세요.

> **주의:** 문서 폴더 안의 이 폴더는 **지우면 안 됩니다.** 지우면 확장 프로그램이 꺼집니다.

## 윈도우 3단계. 잘 됐는지 확인하기

1. 클로드 코드를 **완전히 껐다가 다시 켭니다.**
   (Ctrl + C 두 번으로 끄고, `claude` 로 다시 실행)
2. 입력창에 **/mcp** 라고 치고 Enter를 누릅니다.
3. 목록에 **chrome-mcp-stdio** 가 보이면 설치 완료입니다.

> 재시작을 꼭 해야 합니다. 클로드 코드는 켜질 때 한 번만 도구 목록을 읽기 때문에,
> 재시작 전에는 새로 설치한 것이 보이지 않습니다.

### 바로 시험해 보기

클로드에게 이렇게 말해 보세요.

> 크롬으로 네이버 열어서 오늘 날씨 알려줘

크롬이 뒤에서 조용히 움직이면서 결과를 가져오면 성공입니다.

## 윈도우 문제 해결

**가장 쉬운 방법**은 화면에 나온 오류 메시지를 **그대로 복사해서 클로드 코드에 붙여넣고**
"이거 왜 안 돼?" 라고 물어보는 것입니다. 클로드가 원인을 찾아 고쳐줍니다.
설치할 때 진단 도구도 같이 깔리기 때문에 클로드가 스스로 점검할 수 있습니다.

직접 확인하고 싶다면 파워셸에 이렇게 쳐보세요.

```
auto-chrome-mcp-bridge doctor
```

10개 항목이 나오는데 전부 OK 면 정상입니다.
**Connectivity** 만 실패한다면 크롬이 꺼져 있거나 2단계(확장 등록)를 아직 안 한 것입니다.

**윈도우 사용자는 여기까지입니다.** 마지막의 "이걸 설치하면 뭐가 좋은가요"로 넘어가세요.

# 2부. 맥

맥 사용자는 여기만 따라 하시면 됩니다. (1부는 윈도우 전용이니 건너뛰셔도 됩니다.)

## 맥 0단계. 클로드 코드 설치하기

이미 클로드 코드를 쓰고 계시면 **1단계로 건너뛰세요.**

### 터미널(Terminal) 여는 법

컴퓨터에 글자로 명령을 내리는 창입니다. 검은 화면이 낯설겠지만 몇 줄만 붙여넣습니다.

1. **⌘(커맨드) + 스페이스**를 누릅니다.
2. **터미널** 이라고 칩니다.
3. "터미널(Terminal)" 이 나오면 **Enter**를 누릅니다.

### 설치 명령 붙여넣기

아래 줄을 복사해서 창에 **⌘ + V**로 붙여넣고 Enter를 누릅니다.

```
curl -fsSL https://claude.ai/install.sh | bash
```

설치가 끝나면 창을 닫고 **새로 엽니다.** 방금 설치한 프로그램을 컴퓨터가 인식하게 하려는 것입니다.

### 로그인

새 창에 이렇게 치고 Enter:

```
claude
```

브라우저가 열리면서 로그인하라고 나옵니다. 클로드 계정으로 로그인하면 됩니다.
로그인이 끝나면 클로드 코드가 실행됩니다.

## 맥 1단계. 명령 한 줄 붙여넣기

이제 크롬 MCP를 설치합니다.

> 클로드 코드가 실행 중이라면 먼저 빠져나와야 합니다. **Ctrl + C를 두 번** 누르면 됩니다.
> 맥에서도 ⌘가 아니라 **Ctrl** 입니다.

터미널에 아래 한 줄을 붙여넣고 Enter를 누르세요.

```
curl -fsSL https://raw.githubusercontent.com/cw02326/auto-chrome-mcp/main/install.sh | bash
```

이제 기다리면 됩니다. 2분에서 5분쯤 걸립니다. 이 한 줄이 이런 일을 알아서 합니다.

- 크롬과 클로드를 연결하는 통로 만들기
- 클로드 코드에 등록
- 크롬 확장 프로그램 내려받기

> **"Node.js 가 없습니다" 라고 나왔다면?**
> 홈브류가 있으면 터미널에 `brew install node` 를 치세요.
> 없으면 nodejs.org 에서 받아 설치한 뒤, 위 명령을 다시 실행하면 됩니다.

> **권한 오류(EACCES)가 났다면?**
> 아래 두 줄을 차례로 실행한 뒤 위 명령을 다시 실행하세요.
> **`sudo` 는 쓰지 마세요.** 지금은 되는 것 같아도 나중에 더 꼬입니다.
>
> ```
> npm config set prefix ~/.npm-global
> echo 'export PATH="$HOME/.npm-global/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
> ```

1단계가 끝나면 **폴더 창**이 하나 열립니다. 여기가 확장 프로그램이 들어 있는 폴더입니다.
위치는 **서류(Documents) > AutoChromeMCP-확장프로그램** 입니다.

> 윈도우와 달리 **크롬 화면은 자동으로 열리지 않습니다.** 직접 여셔야 합니다.

1. 크롬을 열고 주소창에 **chrome://extensions** 를 입력한 뒤 Enter를 누릅니다.
2. 화면 **오른쪽 위**의 **개발자 모드** 스위치를 켭니다. 파란색이 되면 켜진 것입니다.

   **서류 > AutoChromeMCP-확장프로그램** 폴더를 고른 뒤 **선택**을 누릅니다.

목록에 **Auto Chrome MCP** 가 나타나면 성공입니다.

### 1단계가 아예 안 될 때 (대체 방법)

한 줄 설치가 실패하면, 아래 두 줄을 차례로 실행해도 결과는 같습니다.

```
npm install -g auto-chrome-mcp-bridge
```

```
claude mcp add --scope user --transport stdio chrome-mcp-stdio -e CHROME_PORT=12320 -- node "$(npm root -g)/auto-chrome-mcp-bridge/dist/mcp/mcp-server-stdio.js"
```

첫 줄이 확장 프로그램도 같이 내려받습니다.
이 경우 확장 폴더는 **다운로드(Downloads)** 안에 `auto-chrome-mcp-extension-v...` 라는
이름으로 생깁니다. 2단계에서 그 폴더를 고르면 됩니다.

그래도 안 되면 아래 주소에 오류 화면을 올려 주세요.

# 공통. 설치 후 알아두면 좋은 것

여기부터는 윈도우와 맥 모두 해당됩니다.

## 이걸 설치하면 뭐가 좋은가요

**내 화면을 건드리지 않습니다.** 클로드는 뒤쪽 탭에서 조용히 일합니다.
보고 있던 페이지가 갑자기 바뀌지 않습니다.

**말로 시킬 수 있습니다.** "로그인 버튼 눌러줘" 라고 하면 알아서 찾아 클릭합니다.
버튼 이름이나 위치를 알려줄 필요가 없습니다.

**긴 목록도 알아서 모읍니다.** 스크롤을 계속 내려야 나오는 페이지도 끝까지 훑어옵니다.

**상황 변화에 대처합니다.** 로그인 팝업이 뜨거나 파일이 받아지면 알아차리고 이어서 작업합니다.

## 내가 컴퓨터 쓰는 걸 방해하지 않나요 (무간섭 모드)

방해하지 않습니다. 설치한 그대로 두면 AI 가 브라우저를 쓰는 동안 **화면에서 보이는 것은
아무것도 바뀌지 않습니다.**

- AI 가 쓰는 탭은 여러분이 보고 있는 창이 아니라 **따로 만든 작업용 창**에 모입니다.
  그 창은 만들어지자마자 최소화돼서 화면에는 나타나지 않습니다(작업 표시줄에만 남습니다).
- 여러분이 보고 있는 탭이 다른 탭으로 바뀌는 일이 없습니다.
- 크롬 창이 다른 프로그램 앞으로 튀어나오지 않습니다.

혹시 크롬이 앞으로 튀어나온다면 확장 아이콘을 눌러 팝업에서 **강제 포커스** 스위치가 켜져
있는지 보세요. 켜져 있으면 끄면 됩니다. 예전 버전을 쓰다가 설정을 바꿨던 분은 팝업의
**"무간섭 권장 설정으로 되돌리기"** 버튼을 한 번 누르면 권장값으로 정리됩니다.

작업용 창이 보이는 게 오히려 편하다면 팝업의 **작업 창 배치** 를 "보이게" 로 바꾸면 됩니다.

## 권한과 보안

이 프로그램은 자동화가 중간에 멈추지 않도록 크롬의 일부 권한을 미리 허용해 둡니다.
팝업, 알림, 클립보드, 자동 다운로드 네 가지입니다.

카메라, 마이크, 위치는 다르게 다룹니다. 클로드가 실제로 그 기능을 쓰려는 사이트에만
하나씩 허용되고, 크롬 확장 아이콘을 눌러 나오는 설정에서 "쓸 때마다 물어보기"로 바꿀 수 있습니다.

운영체제 설정도 필요합니다. 여기서 막혀 있으면 크롬이 아무리 허용해도 동작하지 않습니다.

- **윈도우**: 설정 > 개인 정보 보호 > 카메라 / 마이크 / 위치
- **맥**: 시스템 설정 > 개인정보 보호 및 보안 > 카메라 / 마이크 / 위치

민감한 작업(회사 계정, 금융)에 쓰신다면 **크롬 프로필을 따로 만들어** 거기에만 설치하는 것을
권합니다. 크롬 오른쪽 위 프로필 아이콘에서 새 프로필을 만들 수 있습니다.
